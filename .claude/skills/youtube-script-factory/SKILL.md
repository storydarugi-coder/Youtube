# YouTube Script Factory

조회수가 검증된 **레퍼런스 영상의 대본/자막 1~3개**를 받아서, 그 성공 패턴을 기반으로 새 영상의 풀 패키지(분석 → 대본 → 스토리보드 → 업로드 정보 → 썸네일)를 한 번에 만든다.

## 입력

사용자가 **레퍼런스 대본 또는 자막 텍스트** 1~3개를 붙여넣는다. 이미 조회수가 잘 나온 영상의 스크립트가 분석 재료가 된다.

(레퍼런스가 1개여도 진행 가능. 다만 패턴 추출 정확도가 떨어짐 → 이 경우 사용자에게 "최소 2~3개 권장" 안내 후 그대로 진행)

## 8단계 처리 흐름

### 1단계 — 성공요인 분석

레퍼런스를 깊게 분석한다. **"왜 이 영상이 잘 됐는가"**를 역분석하는 것이 핵심.

분석 항목:
- **구조**: 0~15초 오프닝 훅의 패턴, 본론 전개 방식, 클라이맥스 위치, 엔딩 처리
- **톤·말투**: 구어체 강도, 시청자와의 거리감, 감탄 빈도
- **시청 유지 장치**: 오픈 루프, 전환 문구, 궁금증 유발 기법
- **콘텐츠 전략**: 정보/스토리 비율, 반전 포인트, 감정 설계
- **잘 먹힌 이유**: 호기심·논쟁·반전·감정 중 무엇을 자극하는가
- **차별화 요소**: 일반적 영상과의 차이

레퍼런스가 여러 개면 **공통 패턴**과 **개별 강점**을 모두 정리. 이게 이후 모든 단계의 토대.

### 1.5단계 — 주제·타겟·제목 추천 (사용자 선택)

1단계 분석을 토대로 새 영상에 대해 아래 셋을 각각 **3개씩** 추천하고 사용자에게 선택받는다.

1. **주제 후보 3개** — 레퍼런스의 성공 패턴을 재현 가능한 신규 주제
2. **타겟층 후보 3개** — 연령대 / 관심사 / 시청 동기를 구체적으로
3. **제목 방향 후보 3개** — 충격형 / 질문형 / 대비형 / 리스트형 / 스토리텔링형 중 3개 선정

> 이 단계는 유일한 인터랙티브 지점. 사용자가 "1, 2, 1" 식으로 선택하거나 "주제 1번, 제목은 새로 제안"처럼 답하면 다음 단계로.

### 2단계 — 팩트체크 (web_search ≥ 3회)

선택된 주제의 핵심 사실관계를 교차 검증한다.

- 인물·날짜·사건의 정확성
- 대중적으로 알려진 내용 중 오류
- 학술적 논쟁이 있는 부분 식별
- 출처가 다른 검색 결과 최소 3회 이상 비교

### 3단계 — 추가 정보 수집 (web_search ≥ 3회)

대본을 풍부하게 만들 소재 발굴.

- 흥미로운 일화, 뒷이야기, 반전 사실
- 인물의 인용구·기록
- 현대와의 연결고리
- 시각자료로 쓸 만한 장소·유물 정보

### 4단계 — 대본 작성

`references/script-guide.md`를 먼저 읽고 그 가이드에 따라 작성.

기본 구조:
- 오프닝 훅 (0~15초): 즉시 사로잡는 강렬한 시작
- 배경 설정 (15초~1분): 왜 중요한지 맥락 제공
- 본론 (1분~본론 끝): 3~4개 파트, 각 파트에 소제목과 전환 문구
- 클라이맥스: 가장 강렬한 순간 (반전·충격·감동)
- 엔딩: 여운 + 생각할 거리
- 아웃트로 (마지막 15초): 구독·좋아요·다음 영상 예고

**구어체 필수**. 분량은 분당 약 300자 (8분 영상 ≈ 2,500자, 13분 ≈ 4,000자).

### 5단계 — 자체 검토·수정

작성된 대본을 아래 기준으로 자체 검토하고 직접 수정. 사용자에게 묻지 않음.

- 팩트 오류 없음
- 0~15초가 충분히 강렬
- 2분 이상 단조 구간 없음
- 감정 곡선이 자연스러움 (긴장-이완-긴장-클라이맥스)
- 전문 용어가 시청자에게 어렵지 않음
- 분량 적정
- 구어체 자연스러움

### 6단계 — 스토리보드

대본을 씬 단위로 분할하고 표로 정리.

| 씬 # | 자막/내레이션 | 영어 이미지 프롬프트 | 길이(초) |
|------|--------------|---------------------|----------|
| 1 | ... | ... | ... |

이미지 프롬프트는 `references/image-prompt-guide.md`의 5요소(주체·배경·분위기·구도·스타일) 템플릿을 따른다. 같은 영상 안의 모든 프롬프트는 동일한 스타일 프리픽스를 공유해서 일관성 유지.

### 7단계 — 업로드 정보

`references/title-guide.md` 참고하여 메타데이터 생성.

- **제목**: SEO + CTR 균형. 한글 15~25자. 1.5단계에서 사용자가 선택한 방향 반영.
- **설명**: 1,500~2,000자. 도입 2~3문장 + 타임스탬프 + 핵심 요약 + 해시태그
- **태그**: 15~20개 (대주제·소주제·롱테일 키워드 균형)
- **카테고리**: 적절한 유튜브 카테고리 1개

### 8단계 — 썸네일 프롬프트 3종

`references/thumbnail-guide.md` 참고하여 서로 다른 전략의 프롬프트 3개.

1. **감정 중심** — 강렬한 표정/감정을 전면에
2. **대비/충돌 중심** — 시각적 대비 활용
3. **미스터리/호기심 중심** — 궁금증 유발

각 프롬프트에 포함:
- 영어 이미지 프롬프트 (상세)
- 텍스트 오버레이 제안 (한국어, 2~5단어)
- 이 전략이 이 주제에 효과적인 이유 한 줄

## 출력 형식

전체를 하나의 마크다운 문서로 출력. 각 단계를 `##` 헤더로 구분.

```
## 1. 성공요인 분석
...

## 1.5. 주제·타겟·제목 추천
(3×3 후보 → 사용자 선택 대기)

## 2. 팩트체크
...

## 3. 추가 정보
...

## 4. 대본
...

## 5. 검토·수정 사항
...

## 6. 스토리보드
(표)

## 7. 업로드 정보
- 제목 / 설명 / 태그 / 카테고리

## 8. 썸네일 프롬프트
- A: 감정 중심
- B: 대비 중심
- C: 미스터리 중심
```
