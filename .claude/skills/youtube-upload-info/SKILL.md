# YouTube Upload Info Generator

완성된 유튜브 대본을 받아서 업로드에 필요한 모든 메타데이터를 즉시 생성한다.

## 입력

사용자가 **완성된 대본 텍스트**를 붙여넣는다. 추가 질문 없이 바로 생성 시작.

## 생성 항목

### 1. 제목

`references/title-guide.md`를 먼저 읽고 가이드에 따라 작성.

- SEO + CTR 모두 고려한 최적 제목 1개를 직접 결정
- 대본의 **핵심 주제 / 반전 포인트 / 감정 클라이맥스** 반영
- 한글 기준 **15~25자** (모바일에서 안 잘리는 선)

### 2. 설명 (Description)

다음 구조로 작성:

```
(영상 내용을 요약하는 도입 2~3문장)

📌 타임스탬프
00:00 (오프닝)
00:15 (첫 번째 파트 제목)
...

(영상에서 다룬 핵심 내용 요약 3~5문장 — 검색 키워드를 자연스럽게 포함)

#해시태그1 #해시태그2 #해시태그3 ...
```

- 총 분량: **1,500~2,000자**
- 타임스탬프는 대본의 파트/소제목 구분을 기반으로 추정
- SEO 키워드를 자연스럽게 녹임 (키워드 나열 X)

### 3. 태그

- 관련 검색 키워드 **15~20개**
- **균형 배합**:
  - 대주제 태그 (예: 한국사, 역사)
  - 소주제 태그 (예: 임진왜란, 이순신)
  - 롱테일 키워드 (예: 조선시대 해전 전략)
- 쉼표로 구분

### 4. 카테고리

유튜브 카테고리 중 가장 적절한 것 1개 (교육 / 엔터테인먼트 / 인물 블로그 / 뉴스 정치 / 게임 / 음악 등).

### 5. 썸네일 프롬프트 3종

`references/thumbnail-guide.md`를 먼저 읽고 가이드에 따라 작성.

서로 다른 전략의 프롬프트 3개:
1. **감정 중심** — 강렬한 표정/감정을 전면에
2. **대비·충돌 중심** — 시각적 대비 활용
3. **미스터리·호기심 중심** — 궁금증 유발

각 프롬프트에 포함:
- 영어 이미지 프롬프트 (상세)
- 텍스트 오버레이 제안 (한국어, 2~5단어)
- 이 전략이 효과적인 이유 한 줄

## 레퍼런스 파일

| 파일 | 용도 |
|------|------|
| `references/title-guide.md` | 제목 전략 |
| `references/thumbnail-guide.md` | 썸네일 전략 및 프롬프트 가이드 |
